# Clarification Policy

Ask only when the answer can change PRD coverage, epic ownership, cross-epic sequencing, blocking open questions, ADR requirements, or the validation decision.

Do not ask for information that can be discovered from repository context, existing planning artifacts, concern specs, documentation, or code.

If ambiguity is non-blocking, proceed with a clear assumption and record it in the affected epic validation section.

If ambiguity blocks PRD-to-epic validation quality, stop and ask one to three concrete questions. Prefer questions that name the PRD item or epic boundary being blocked.
