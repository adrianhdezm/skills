# Clarification Policy

Ask only when the answer can change final state, closure reason, validation acceptance, archived contents, deferred work, or remaining risk.

Do not ask for information that can be discovered from repository context, existing planning artifacts, concern specs, documentation, or code.

If ambiguity is non-blocking, proceed with a clear assumption and record it in `docs/epics/archived/<epic>/archive-summary.md`.

If ambiguity blocks accurate archiving, stop and ask one to three concrete questions.
