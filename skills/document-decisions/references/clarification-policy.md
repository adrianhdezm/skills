# Clarification Policy

Ask only when the answer can change the decision, status, alternatives, consequences, owner, affected concerns, or future interpretation.

Do not ask for information that can be discovered from repository context, existing planning artifacts, concern specs, documentation, or code.

If ambiguity is non-blocking, proceed with a clear assumption and record it in the ADR.

If ambiguity blocks durable rationale, stop and ask one to three concrete questions.
