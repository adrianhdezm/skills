# Clarification Policy

Ask only when the answer can change PRD coverage, candidate boundaries, overlap with existing epics, sequencing, risk, ownership, or whether a candidate should be created.

Do not ask for information that can be discovered from repository context, existing planning artifacts, concern specs, documentation, or code.

If ambiguity is non-blocking, proceed with a clear assumption and include it with the affected candidate.

If ambiguity blocks useful suggestions, stop and ask one to three concrete questions. Prefer questions that name the PRD item, candidate boundary, or overlap being blocked.
