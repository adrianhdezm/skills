# Clarification Policy

Ask only when the answer can change epic coverage, task ownership, verification safety, acceptance criteria mapping, blocking open questions, or the validation decision.

Do not ask for information that can be discovered from repository context, existing planning artifacts, concern specs, documentation, or code.

If ambiguity is non-blocking, proceed with a clear assumption and record it in `docs/epics/active/<epic>/tasks.md`.

If ambiguity blocks epic-to-task validation quality, stop and ask one to three concrete questions. Prefer questions that name the epic topic or verification gap being blocked.
